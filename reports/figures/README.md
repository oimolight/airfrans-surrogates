# Figures

Committed figures must trace to a run or summary. Axes, units, case counts and run IDs are documented in the corresponding report. Figures are evidence views, not replacements for machine-readable metrics.

Model-comparison figures are rendered with Plotly and Kaleido. One-case mesh diagnostics use PyVista. The committed model-comparison figures can be refreshed from the saved JSON and NPZ evidence without model inference.
